# 🎮 快捷键训练营

把发行版里真实在用、但「学了不用就忘」的键位做成 14 个小关卡，边玩边练。
零联网、零新增依赖，只用到本包已随包分发的插件与内置能力。

```
<leader>tt      开始一局（空格 + t + t）
<leader>tT      提前结束，看段位
```

## 怎么玩

1. 按 `<leader>tt`，屏幕上出现一个练习缓冲区，右上角浮窗是记分板
2. 按**浮窗里写的目标**操作缓冲区；**做对了会自动进入下一关**（无需确认）
3. 卡住就 `<leader>th` 看提示（扣 30 分），实在不会 `<leader>tn` 跳过（扣 50 分）

| 局内键位 | 作用 |
| --- | --- |
| `<leader>th` | 看提示（扣分） |
| `<leader>tn` | 跳过本题（扣分） |
| `<leader>tr` | 重做本题 |
| `<leader>tq` | 退出训练营 |

这些键是**练习缓冲区局部**的，不会影响你平时的 lua 文件。

## 14 个关卡

| # | 关卡 | 练的是什么 | 标准答案 |
| --- | --- | --- | --- |
| 1 | 整行删除 | 行级删除 | `dd` |
| 2 | 改掉光标下的单词 | 文本对象 + 编辑 | `ciw` |
| 3 | 注释整行 | 智能注释（认 commentstring） | `gcc` |
| 4 | 给单词加引号 | mini.surround 添加 | `saiw"` |
| 5 | 去掉括号 | mini.surround 删除 | `sd(` |
| 6 | 复制整行到下面 | 复制粘贴 | `yyp` |
| 7 | 整行变大写 | 大小写转换 | `gUU` |
| 8 | 缩进一行 | 缩进（宽度 2） | `>>` |
| 9 | 文本对象：整个函数 | treesitter 文本对象 | `daf` |
| 10 | 闪跳 | flash 标签跳转 | `s` + 字符 + 标签 |
| 11 | 搜索并跳到匹配 | `/` 搜索 | `/target_word` |
| 12 | 中文按词移动 | jieba 分词接管 `w` | `w`… |
| 13 | 宏：一次处理多行 | 录制与执行宏 | `qa` … `q` 然后 `@a` |
| 14 | 重复上一次修改 | 点号重复 | `A=` 然后 `j` `.` |

## 计分与段位

| 项目 | 规则 |
| --- | --- |
| 每题基础分 | 100 |
| 提示 | 每次 −30 |
| 连击 | 每多一级 +20%（最多 +100%） |
| 跳过 | −50，且连击清零 |
| 段位 | 按总分/满分：≥95% S，≥80% A，≥60% B，≥40% C，其余 D |

历史最高分存在发行版自己的 `stdpath('state')/tutor.json`，
不写系统别处，也不联网。

## 设计说明（为什么这么实现）

- **每关都可程序化验证。** 判据是「缓冲区内容/光标是否达到目标」，
  而不是「你有没有按某个键」——所以你用别的等价手法过关也算，
  但**不动手绝对过不了**（14 关都写了「未操作必须为 false」的测试）。
- **练习缓冲区不用 `lua` 文件类型。** 否则 `lua_ls` 会附着上来，
  左栏出现诊断标记，干扰练习。注释关卡需要 `commentstring`，
  单独在缓冲区上设成 `-- %s`。
- **第 9 关显式挂 lua 解析器。** treesitter 文本对象需要解析器，
  但那不代表整个练习缓冲区要变成 lua 文件类型。
- **自动判定有 150ms 防抖。** 每次按键都跑一遍 check 太浪费；
  编辑与光标事件合并后再判一次。
- **没有时间上限。** 计时只用于统计与段位参考，不做「时间到就失败」——
  那会让新手在第 1 关就被劝退。
